# Nothing Pakistan

## Setup

1. Open a terminal in this folder.
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. For a production check:

```bash
npm run check
```

The project uses React + TypeScript + Vite. The navigation uses client-side history routes for `/`, `/shop`, `/buying-guide`, `/compare`, `/reviews`, and `/blog`.
